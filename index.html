Core Network Protocols

The Internet functions as a "Network of Networks" using a common set of rules known as the Internet Protocol Suite. The OSI 7-Layer Model and TCP/IP Model provide different conceptual abstractions.

The OSI model is theoretical, while TCP/IP is the practical implementation used in modern networking.

Key Distinction

"The OSI model defines functions; the TCP/IP model defines protocols."

Cybersecurity Basics

The TLS 1.3 Handshake

Securing the internet requires robust encryption during transit. The TLS (Transport Layer Security) handshake is the process where client and server negotiate encryption keys.

  1. Client Hello: Proposes cipher suites and sends random nonce.
  2. Server Hello: Selects cipher and sends digital certificate.
  3. Authentication: Client verifies certificate with Root CA.
  4. Key Exchange: Ephemeral keys are generated for session encryption.
